# 轻账单 LiteBill

本地优先的个人记账 PWA（纯前端，无需后端、无需安装依赖）。

数据只保存在你的浏览器 localStorage 中，不经过任何服务器，隐私安全。

## 功能

- **记账**：支出 / 收入 / 转账，自定义分类（一级 + 二级）、账户、优惠（原价 − 优惠 = 优惠后，三字段任意联动）、多行备注、历史备注联想
- **文字记账**：输入一句话自动识别 账户 / 分类 / 金额 / 备注，如「现金买零食花了68」→ 账户现金、分类休闲零食、支出68元；支持多行加和
- **分类**：按使用频率自动排序；图标库含 60+ 线条简约图标（可上传自定义图片）、马卡龙配色
- **账户**：多账户管理、专属详情页（余额 + 收入/支出 + 周期账单）、账户间转账（可选手续费、附件）、计入总资产开关
- **统计**：日常 / 月 / 年 / 自定义 四页，收支柱状图、资产走势、收支对比、收支占比、一级分类排行（可点击进分类专属页）
- **预算**：月度总预算 + 分类预算，进度条实时提醒
- **借贷**：应收 / 应付 / 借贷账户管理，到期提醒
- **周期账单**：房租、订阅等固定收支，到期一键入账并自动顺延
- **日历**：滑动切月、月份跳转、按日查看
- **记账提醒**：每天 / 每周 / 每月定时提醒（应用打开时生效）
- **导入导出**：JSON 备份（完整数据）、Excel / CSV 导入、CSV 导出、截图文字识别（已移除 OCR）
- **PWA**：可安装到桌面（设置 → 关于 → 安装到桌面），离线可用，自动检查更新 / 从网址更新

## 快速开始

本项目为纯静态文件，直接打开或用任意静态服务器即可：

```bash
# 本地预览（Node.js 自带 http 或本项目 server.js）
node server.js 8123
# 浏览器打开 http://localhost:8123
```

也可以直接把整个目录部署到任意静态托管（GitHub Pages / Netlify / 对象存储等）。

## 项目结构

```
litebill/
├── index.html            # 入口页面（含 PWA 注册）
├── manifest.webmanifest  # PWA 清单（安装到桌面）
├── sw.js                 # Service Worker（离线缓存，改版需同步缓存名）
├── _headers              # Netlify 响应头（sw/index 不缓存）
├── server.js             # 本地预览服务器（带 CORS）
├── css/style.css         # 全部样式（马卡龙主题）
├── js/
│   ├── preset.js         # 预设数据：分类、账户类型、支付品牌、线条图标、配色
│   ├── store.js          # 数据层：localStorage 持久化、CRUD、统计计算、迁移
│   ├── ui.js             # UI 工具：图标渲染、金额解析、弹窗/Toast
│   ├── charts.js         # 图表：环形图、柱状图、折线图（纯 SVG）
│   ├── views.js          # 视图层：各页面渲染与交互
│   └── app.js            # 主逻辑：路由、全局事件、键盘、导入导出、主题
├── icons/                # PWA 图标（可脚本重新生成）
└── scripts/gen-icons.js  # 图标生成脚本
```

## 数据说明

- 数据存储在浏览器 localStorage（键 `litebill.data.v1`），**清除浏览器数据前请先导出备份**
- 换设备 / 换域名迁移：设置 → 数据管理 → 导出备份 (JSON)，再到新环境导入
- 导入备份会**替换**当前全部数据
- Service Worker 缓存版本号与 `js/app.js` 的 `APP_VERSION` 保持一致，发布新版本时需同步更新 `sw.js` 缓存名、`index.html` 页脚、`views.js` 关于页

## 开发提示

- 无构建步骤：直接改 `js/`、`css/` 后刷新即可
- 版本号需同步 4 处：`sw.js`（CACHE 名）、`index.html`（页脚）、`js/views.js`（关于页）、`js/app.js`（`APP_VERSION`）
- 文件编码必须为 UTF-8（无 BOM），否则中文会乱码
- 已内置 jsdom 回归测试流程（见 `.dev-litebill-test`，测试脚本用完即删）

## 隐私

- 所有数据仅保存在本设备浏览器中
- 无账号、无服务器、无第三方统计
- 截图识别（OCR）与语音识别功能已移除，保留轻量的文字记账
